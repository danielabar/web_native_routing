About This Project

This project demonstrates how to build a single-page application using only native web APIs, following the "anti-frameworkism" philosophy outlined in modern web development discussions.

The Philosophy

Modern browsers can handle most of the problems that frontend frameworks were originally created to solve. Instead of defaulting to heavy frameworks, we can start with the web platform and add complexity only when needed.

Technical Implementation

  • History API - For client-side routing and browser navigation
  • Fetch API - For loading HTML templates dynamically
  • Native Events - For handling user interactions and navigation
  • Modern CSS - For layout and styling without JavaScript dependencies

Benefits

  • Fast initial page load (2-3KB total JavaScript)
  • No build step or compilation required
  • Future-proof - built on web standards
  • Easy to understand and debug
  • Great for simple to medium complexity sites

Note: This approach works best for content-focused sites with moderate interactivity. For complex applications with heavy state management needs, a framework might still be the better choice.
