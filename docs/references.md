# Web API References

This document provides MDN Web API references specifically for the routing, navigation, and dynamic loading functionality used in the router.

## History API
- **[History API](https://developer.mozilla.org/en-US/docs/Web/API/History_API)** - Complete API documentation
- **[History.pushState()](https://developer.mozilla.org/en-US/docs/Web/API/History/pushState)** - Add entries to browser history
- **[History.replaceState()](https://developer.mozilla.org/en-US/docs/Web/API/History/replaceState)** - Modify current history entry
- **[popstate event](https://developer.mozilla.org/en-US/docs/Web/API/Window/popstate_event)** - Handle browser back/forward navigation

## Location API
- **[Location](https://developer.mozilla.org/en-US/docs/Web/API/Location)** - Current document location
- **[Location.pathname](https://developer.mozilla.org/en-US/docs/Web/API/Location/pathname)** - URL path portion
- **[Location.hostname](https://developer.mozilla.org/en-US/docs/Web/API/Location/hostname)** - Domain name

## Fetch API
- **[Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API)** - Modern HTTP requests
- **[fetch()](https://developer.mozilla.org/en-US/docs/Web/API/fetch)** - Make network requests
- **[Response](https://developer.mozilla.org/en-US/docs/Web/API/Response)** - Handle fetch responses
- **[Response.ok](https://developer.mozilla.org/en-US/docs/Web/API/Response/ok)** - Check successful responses
- **[Response.text()](https://developer.mozilla.org/en-US/docs/Web/API/Response/text)** - Extract response as text

## Dynamic Imports
- **[import()](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/import)** - Dynamic module imports
- **[ES6 Modules](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules)** - Module system overview

## DOM APIs
- **[Document.getElementById()](https://developer.mozilla.org/en-US/docs/Web/API/Document/getElementById)** - Select element by ID
- **[Document.querySelectorAll()](https://developer.mozilla.org/en-US/docs/Web/API/Document/querySelectorAll)** - Select multiple elements
- **[Element.closest()](https://developer.mozilla.org/en-US/docs/Web/API/Element/closest)** - Find closest matching ancestor
- **[Element.getAttribute()](https://developer.mozilla.org/en-US/docs/Web/API/Element/getAttribute)** - Get attribute values
- **[Element.innerHTML](https://developer.mozilla.org/en-US/docs/Web/API/Element/innerHTML)** - Get/set HTML content
- **[Element.classList](https://developer.mozilla.org/en-US/docs/Web/API/Element/classList)** - Manage CSS classes
- **[EventTarget.addEventListener()](https://developer.mozilla.org/en-US/docs/Web/API/EventTarget/addEventListener)** - Register event handlers

## Event APIs
- **[Event.preventDefault()](https://developer.mozilla.org/en-US/docs/Web/API/Event/preventDefault)** - Prevent default behavior
- **[click event](https://developer.mozilla.org/en-US/docs/Web/API/Element/click_event)** - Handle click interactions

## Global Objects
- **[Window](https://developer.mozilla.org/en-US/docs/Web/API/Window)** - Browser window object
- **[console](https://developer.mozilla.org/en-US/docs/Web/API/console)** - Browser console for debugging
